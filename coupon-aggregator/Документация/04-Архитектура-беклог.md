# Архитектура и Backlog

**Версия:** 1.0  
**Проект:** Агрегатор купонов на продукты (MVP)

---

## 1. Архитектура системы

```
                          ┌─────────────────────┐
                          │     Cloudflare       │
                          │   (DNS, CDN, WAF)    │
                          └─────────┬───────────┘
                                    │
                          ┌─────────▼───────────┐
                          │    Next.js (Vercel) │
                          │  App Router + RSC   │
                          │  API Routes         │
                          │  Server Actions     │
                          └───┬─────────────┬───┘
                              │             │
                    ┌─────────▼──┐   ┌──────▼──────┐
                    │ PostgreSQL │   │    Redis     │
                    │ (Neon/RDS) │   │  (BullMQ)   │
                    │  main DB   │   │  queue+cache │
                    └────────────┘   └──────┬───────┘
                                             │
                                    ┌────────▼────────┐
                                    │  Telegram Bot   │
                                    │  (автопостинг)  │
                                    └─────────────────┘
```

### Ключевые решения

| Решение | Вариант | Почему |
|---------|---------|--------|
| **Framework** | Next.js App Router | Единый стек, SSR, RSC, API — всё в одном |
| **Database** | PostgreSQL (managed) | Реляционные данные, миграции, надёжность |
| **Queue** | Redis + BullMQ | Периодическая модерация, проверка купонов |
| **Hosting** | Vercel / облачный add-on | Serverless-деплой, масштабирование, Preview Deploy |
| **Telegram** | Bot API + Webhook | Минимум инфраструктуры, готовые библиотеки |
| **UI** | Tailwind CSS v4 + shadcn/ui | Быстрая разработка, яркий дизайн |
| **ORM** | Prisma | Типизация, миграции, удобство |

### Основные компоненты

#### Frontend (Next.js App Router)

```
app/
├── (public)/           # Публичные страницы
│   ├── page.tsx        # Главная
│   ├── stores/         # /stores — каталог магазинов
│   ├── stores/[slug]/  # /stores/kupers — страница магазина
│   ├── coupons/        # /coupons — все купоны
│   ├── coupon/[id]/    # /coupon/123 — карточка купона
│   └── search/         # /search?q=... — результаты поиска
├── admin/              # Админ-панель (basic)
├── api/                 # API Routes
│   ├── coupons/        # CRUD купонов
│   ├── clicks/         # Трекинг переходов
│   └── telegram/       # Telegram webhook
└── layout.tsx          # Корневой layout
```

#### Backend (API Routes + Server Actions)

- **CRUD coupons/stores** через API Routes + Prisma
- **Трекинг кликов:** Server Action → запись в clicks → редирект с CPA-ссылкой
- **Модерация очередь:** через BullMQ jobs (import → pending_check → active)
- **Telegram posting:** cron job раз в N часов → свежие купоны → канал

#### Telegram-канал

- **Бот:** через `grammy` или `telegraf`
- **Webhook:** POST /api/telegram/webhook
- **Автопостинг:** раз в 6 часов подборка свежих купонов
- **Click_id:** каждая ссылка в посте содержит click_id
