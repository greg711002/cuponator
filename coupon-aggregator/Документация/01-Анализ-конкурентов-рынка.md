**Дата:** 19 сентября 2026

**Категория:** Продукты, доставка еды, фастфуд, рестораны

---

## 1. Обзор рынка

Российский рынок купонных сайтов прошёл несколько этапов:

| Период | Состояние |
|--------|-----------|
| 2010–2012 | Бум: ~140 сервисов, огромные маркетинговые бюджеты |
| 2013–2015 | Схлопывание пузыря: массовый уход недобросовестных игроков |
| 2016–2019 | Консолидация: осталось ~10–15 серьёзных игроков |
| 2020–2026 | Стабилизация: рост 10–15% в год, фокус на качестве |

**Ключевые цифры:**
- Проникновение в России: **2–3%** населения (в США ~10%) → потенциал 3-кратного роста
- Рынок насыщен, но есть ниши
- Уверенный рост поискового спроса по запросу «промокод» каждый год
- Тренд 2026: персонализация купонов вместо массовых промокодов

## 3. Модели монетизации

| Модель | Как работает | Примеры | Комиссия |
|--------|-------------|---------|----------|
| **CPA (Cost Per Action)** | Платформа получает % за приведённого покупателя | Promokodex, Picodi | 0.5–10% с продажи |
| **Фиксированная плата** | Магазин платит за размещение | Boombate, Gilmon | Индивидуально |
| **Платные купоны** | Пользователь платит за купон | Kupikupon | 50–100 ₽ |
| **Реклама** | Баннеры, контекст | Почти все | CPM/CPC |
| **Кэшбэк** | Возврат % от покупки | Biglion (новое) | Зависит от партнёра |

### Рекомендация для MVP: **CPA** — самая масштабируемая модель

## 4. Анализ ниши «Продукты» — почему это перспективно

### Аргументы ЗА

| Фактор | Обоснование |
|--------|-------------|
| **Высокая частота** | Еду заказывают ежедневно/еженедельно → высокая вовлечённость |
| **CPA-программы есть** | Яндекс Еда, Kuper, Самокат, Купер, ВкусВилл — все имеют партнёрки |
| **Слабая конкуренция** | Ни один из топ-10 агрегаторов НЕ специализируется ТОЛЬКО на еде |
| **Потенциал роста** | Рынок доставки продуктов в РФ растёт 20–30% ежегодно |
| **Платежеспособность** | Средний чек доставки продуктов — выше, чем у многих товаров |
| **Акции магазинов** | Пятёрочка, Магнит, Лента, Ашан — регулярные купонные программы |

### Аргументы ПРОТИВ (риски)

| Риск | Комментарий |
|------|-------------|
| Низкая маржа CPA | В еде CPA ниже (1–5%) чем в электронике (до 15%) |
| Сезонность | Пик спроса — перед праздниками, спад — летом |
| Зависимость от партнёров | Условия CPA-сетей может изменить delivery-сервис |
| Конкуренция с крупными сайтами | Универсальные агрегаторы уже имеют разделы еды |

## 6. Выводы и стратегия

### Резюме

1. **Рынок зрелый, но ниша «продукты» свободна** — нет специализированного агрегатора
2. **CPA-монетизация — правильный выбор** для MVP
3. **Главный фактор успеха — актуальность и достоверность** (нерабочий промокод = потеря пользователя)
4. **Канал трафика MVP:** SEO + Telegram-канал (как PromoLis/Pepper)

### Что делать?

| Шаг | Действие |
|-----|----------|
| 1 | Собрать все доступные CPA-партнёрки доставки/продуктов |
| 2 | Настроить базу промокодов с автообновлением |
| 3 | Запустить страницу с категориями: доставка, продукты, фастфуд, рестораны |
| 4 | Параллельно вести Telegram-канал для быстрого трафика |
| 5 | Ввести ручную верификацию кодов (ключевой фактор доверия) |
