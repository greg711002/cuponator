## 1. Полная схема PostgreSQL

### 1.1 stores — магазины/сервисы доставки

```sql
CREATE TABLE stores (
    id              BIGSERIAL PRIMARY KEY,
    name            VARCHAR(255) NOT NULL,
    slug            VARCHAR(255) UNIQUE NOT NULL,
    logo_url        TEXT,
    description     TEXT,
    website_url     TEXT NOT NULL,
    category_id     BIGINT NOT NULL REFERENCES categories(id),
    cpa_network     VARCHAR(255),          -- название CPA-сети/партнёрки
    cpa_params      JSONB DEFAULT '{}',    -- click_id/subid шаблон, комиссия, контакты
    sort_order      INT DEFAULT 500,
    is_featured     BOOLEAN DEFAULT false,
    is_active       BOOLEAN DEFAULT true,
    created_at      TIMESTAMPTZ DEFAULT NOW(),
    updated_at      TIMESTAMPTZ DEFAULT NOW()
);
```

### 1.2 categories — категории магазинов

```sql
CREATE TABLE categories (
    id              BIGSERIAL PRIMARY KEY,
    name            VARCHAR(255) NOT NULL,
    slug            VARCHAR(255) UNIQUE NOT NULL,
    icon            VARCHAR(50),             -- emoji или иконка
    sort_order      INT DEFAULT 500,
    is_active       BOOLEAN DEFAULT true
);
```

### 1.3 coupons — промокоды/купоны/акции

```sql
CREATE TYPE coupon_status AS ENUM (
    'imported', 'pending_check', 'duplicate', 'active',
    'paused', 'expired', 'rejected', 'archived'
);

CREATE TYPE discount_type AS ENUM (
    'percentage', 'fixed_amount', 'free_delivery', 'bonus',
    'gift', 'other'
);

CREATE TABLE coupons (
    id              BIGSERIAL PRIMARY KEY,
    store_id        BIGINT NOT NULL REFERENCES stores(id),
    title           VARCHAR(500) NOT NULL,
    description     TEXT,
    code            VARCHAR(255),            -- сам промокод (если есть)
    promo_url       TEXT,                    -- прямая ссылка на акцию
    discount_type   discount_type NOT NULL DEFAULT 'percentage',
    discount_value  VARCHAR(100) NOT NULL,   -- "15%", "500р", "бесплатно" итп
    conditions      TEXT,                    -- условия применения
    min_order_amount DECIMAL(10,2),          -- мин. сумма заказа
    starts_at       TIMESTAMPTZ NOT NULL,
    expires_at      TIMESTAMPTZ,
    is_verified     BOOLEAN DEFAULT false,   -- проверен модератором
    verified_at     TIMESTAMPTZ,
    click_count     BIGINT DEFAULT 0,        -- счётчик (denormalized)
    sort_order      INT DEFAULT 500,
    status          coupon_status NOT NULL DEFAULT 'imported',
    priority        INT DEFAULT 5 CHECK (priority BETWEEN 1 AND 10),
    data_source     VARCHAR(255),            -- откуда получен: manual, cpa_network, парсинг
    source_url      TEXT,                    -- оригинальный URL откуда взят код
    meta            JSONB DEFAULT '{}',      -- доп. метаданные
    created_at      TIMESTAMPTZ DEFAULT NOW(),
    updated_at      TIMESTAMPTZ DEFAULT NOW()
);

CREATE INDEX idx_coupons_store_id ON coupons(store_id);
CREATE INDEX idx_coupons_status ON coupons(status);
CREATE INDEX idx_coupons_expires_at ON coupons(expires_at);
CREATE INDEX idx_coupons_discount_type ON coupons(discount_type);
```

### 1.4 clicks — переходы по купонам (CPA-трекинг)

```sql
CREATE TABLE clicks (
    id              BIGSERIAL PRIMARY KEY,
    coupon_id       BIGINT NOT NULL REFERENCES coupons(id),
    click_id        VARCHAR(255) UNIQUE NOT NULL,  -- уникальный идентификатор перехода
    subid           VARCHAR(255),                   -- может быть частью CPA-ссылки
    ip_address      INET,
    user_agent      TEXT,
    referrer        TEXT,
    converted       BOOLEAN DEFAULT false,          -- подтверждение покупки от CPA-сети
    converted_at    TIMESTAMPTZ,
    revenue         DECIMAL(10,4),                  -- CPA-комиссия в ₽
    created_at      TIMESTAMPTZ DEFAULT NOW()
);

CREATE INDEX idx_clicks_coupon_id ON clicks(coupon_id);
CREATE INDEX idx_clicks_click_id ON clicks(click_id);
CREATE INDEX idx_clicks_converted ON clicks(converted);
```

### 1.5 sources — источники данных

```sql
CREATE TABLE sources (
    id              BIGSERIAL PRIMARY KEY,
    name            VARCHAR(255) NOT NULL,
    type            VARCHAR(50) NOT NULL,   -- 'cpa_network', 'manual', 'parser'
    config          JSONB DEFAULT '{}',
    is_active       BOOLEAN DEFAULT true,
    last_sync_at    TIMESTAMPTZ,
    created_at      TIMESTAMPTZ DEFAULT NOW()
);
```

### 1.6 audit_log — журнал изменений

```sql
CREATE TABLE audit_log (
    id              BIGSERIAL PRIMARY KEY,
    entity_type     VARCHAR(50) NOT NULL,   -- 'coupon', 'store', 'user'
    entity_id       BIGINT NOT NULL,
    action          VARCHAR(50) NOT NULL,   -- 'created', 'updated', 'status_changed', 'deleted'
    old_status      coupon_status,
    new_status      coupon_status,
    changes         JSONB DEFAULT '{}',     -- какие поля изменились
    changed_by      VARCHAR(255),           -- 'system', 'admin:<id>', 'parser:<id>'
    reason          TEXT,
    created_at      TIMESTAMPTZ DEFAULT NOW()
);

CREATE INDEX idx_audit_entity ON audit_log(entity_type, entity_id);
CREATE INDEX idx_audit_created_at ON audit_log(created_at);
```

## 2. Жизненный цикл купона

```
        ┌─────────────┐
        │  imported   │ ← Автоматический импорт/парсинг
        └──────┬──────┘
               │
               ▼
        ┌──────────────┐
        │ pending_check│ ← Попадает в очередь модерации
        └──────┬───────┘
               │
        ┌──────┴───────┐
        ▼              ▼
   ┌──────────┐ ┌──────────┐
   │  active  │ │duplicate │ ← Найден дубликат
   └─────┬────┘ └──────────┘
         │
    ┌────┴────┐
    │  paused │ ← Временно скрыт (проблемы с кодом/партнёром)
    └────┬────┘
         │
    ┌────┴──────┐
    ▼          ▼
┌────────┐ ┌────────┐
│ expired│ │rejected│ ← Истёк / отклонён модератором
└────┬───┘ └────────┘
     │
     ▼
┌──────────┐
│ archived │ ← Убран из выдачи, хранится в истории
└──────────┘
```

### Допустимые переходы статусов

| Из | В | Условие |
|----|---|---------|
| `imported` | `pending_check` | Автоматически после импорта |
| `pending_check` | `active` | Прошёл модерацию |
| `pending_check` | `duplicate` | Найден точно такой же активный купон |
| `pending_check` | `rejected` | Модератор отклонил (нерабочий/недостоверный) |
| `active` | `paused` | По запросу партнёра или подозрение на нерабочий код |
| `active` | `expired` | expires_at прошло |
| `paused` | `active` | Повторная проверка прошла |
| `paused` | `expired` | expires_at прошло |
| `paused` | `rejected` | Подтверждена неработоспособность |
| `expired` | `archived` | Автоматически через 30 дней после истечения |
| `rejected` | `archived` | Автоматически через 30 дней после отклонения |

### Периодические проверки

```
Каждые 6 часов:
  → Все active купоны с expires_at < NOW() → expired

Каждые 12 часов:
  → Рандомная выборка active купонов (10%) → перепроверка
  → При ошибке → помечаются для ручной проверки (pending_check)

Каждые 24 часа:
  → expired купоны старше 30 дней → archived
  → rejected купоны старше 30 дней → archived
```

## 3. Click-трекинг (как работают CPA-ссылки)

```
Пользователь → нажимает "Показать код"
       │
       ▼
Генерируется click_id = uuid/v7 + coupon_id
       │
       ▼
Сохраняется запись в clicks()
       │
       ▼
Показывается промокод + кнопка "Перейти в магазин"
       │
       ▼
Переход по ссылке: promo_url?subid={click_id}&utm_source=наш_сайт
       │
       ▼
Магазин фиксирует заказ с subid → CPA-сеть отправляет callback
       │
       ▼
POST-backend → clicks.converted = true, revenue = сумма комиссии
```
