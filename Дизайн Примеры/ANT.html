API Services / API-42

Реализовать лимит запросов для публичных эндпоинтов

Исполнитель
JD
Jane Doe
Статус В работе
Приоритет Высокий
Метки
backend security

Необходимо реализовать ограничение частоты запросов для всех эндпоинтов /api/v1/public/*, чтобы предотвратить злоупотребления и обеспечить стабильность сервиса.

Требования:

  • Лимит: 100 запросов в минуту на IP.
  • Возвращать HTTP 429 Too Many Requests при превышении лимита.
  • Включить заголовки X-RateLimit-Limit и X-RateLimit-Remaining в ответ.
  • Использовать Redis для хранения распределённых счётчиков.

Подробности подключения к Redis смотрите в документации по архитектуре.
